Install antlr4-tools
    Required code changes to antlr4-tools library: see https://github.com/antlr/antlr4-tools/issues/22

Use antlr4 command to generate parser, lexer, and listener: antlr4 -Dlanguage=Python3 ltl.g4 -listener

Review: https://arxiv.org/pdf/1808.03315
See https://spot.lre.epita.fr/tut04.html for how LTL equivalence is determined

stltoeng had a simple pass over to add in lower and upper temporal bounds. Should probably get a proper look to get more appropriate grammar

Where equiv is used:
    applyRandomMutationNotEquivalentTo -- Used to when building exercises to generate randomly mutated false answers that are guaranteed to not be equivalent to the correct answers
    getAllApplicableMisconceptions -- Gets all the known common misconceptions about how a given LTL formula could be formed. For a given formula, gets a bunch of similar, but different, formulas that could be mistaken for the intended one. equiv is used to make sure that the modified formulas aren't equivalent to the original
